# Staw Expert — program kontroli splewki (Argulus)

## 1. Aktualny stan

### Cel
Opracować naukowo uzasadniony, bezpieczny program kontroli Argulus dla oczek i małych stawów ozdobnych, potencjalnie jako podstawa przyszłych produktów/procedur Staw Expert.

### Koncepcja użytkowa
Trzy poziomy programu:
1. kontrola i przeciwdziałanie;
2. wspomaganie odporności i regeneracji ryb;
3. silna kuracja;
plus działania poprawiające parametry wody bez tworzenia warunków korzystnych dla pasożyta.

### Ustalenia metodologiczne
- `REQUIREMENT` Preferować recenzowane badania naukowe; DOI jest wskazany, ale nie zastępuje oceny metodologii.
- `REQUIREMENT` Oceniać gatunek ryby/pasożyta, dawkę, temperaturę, czas ekspozycji, próbę i warunki wody.
- `REQUIREMENT` Oddzielać dane naukowe, dane producenta, SDS/CLP, praktykę branżową i hipotezy.
- `OPEN` Harmonogram zabiegów zależny od temperatury i cyklu rozwojowego wymaga precyzyjnego modelu opartego na źródłach.
- `OPEN` Bezpieczeństwo długiej, około miesięcznej kuracji i wpływ na ryby/biologię filtra wymaga osobnej oceny dla każdej substancji.

## 2. Ryzyka
Toksyczność dla ryb i bezkręgowców, wpływ na filtr biologiczny, pozostałości, niezgodne prawnie zastosowanie substancji, przenoszenie wyników między gatunkami i temperaturami.
